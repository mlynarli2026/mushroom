# 留学选校助手（Study Abroad Guide）

一个**纯静态网站**：帮你（和你的朋友）从 **QS 2027 世界大学排名前 100** 的学校中，
按学校 → 硕士课程 → 课程详情 逐层查找留学申请信息。

## 网站怎么用（3 层结构）

| 页面 | 文件 | 内容 |
|---|---|---|
| 首页 | `index.html` | QS 2027 前 100 学校榜单（102 所，含并列排名） |
| 学校页 | `school.html?id=xxx` | 该校硕士课程 A-Z 列表 + 关键词搜索 |
| 课程页 | `course.html?id=xxx&c=slug` | 官网课程链接 + 中文学费 / 语言 / 绩点 / 申请要求 / 申请时间 |

**搜索规则**（"全部搜索"）：不区分大小写的**包含匹配**。
例如课程名 `Digital Humanities`，输入 `digital` 或 `digital humanities` 都能搜到；
多个词空格分隔时，所有词都必须出现（如 `data science` 可命中 `MSc Data Science`）。

## 如何本地预览（不需要任何安装）

**方法 A（双击打开，最简单）**：直接用浏览器打开 `index.html` 即可。
（数据全部放在 `data/` 下的 `.js` 文件里，不依赖服务器，所以双击就能用。）

**方法 B（如果你想要一个"网址"式访问）**：
```bash
cd uni-guide
python3 -m http.server 8765
```
然后浏览器打开 http://127.0.0.1:8765/

## 数据格式（想手动添加学校/课程的人看这里）

**学校**：在 `data/schools.js` 的 `SCHOOLS` 数组里加一行：
```js
{"id":"xxx","rank":1,"nameCn":"学校中文名","nameEn":"English Name","country":"国家","site":"https://官网"}
```

**课程**：新建 `data/courses/xxx.js`（xxx = 学校 id）：
```js
var SCHOOL_COURSES = {
  "searchUrl": "官网课程检索页",
  "courses": [
    {"id":"slug","title":"Course Title","url":"https://官网课程页",
     "summary":"课程内容中文摘要（阅读官网介绍后撰写）",
     "duration":"学制（如 1年全日制）","teachingLanguage":"授课语言（特殊情况用⚠️标注）",
     "tuition":"学费","language":"语言成绩要求","gpa":"绩点要求",
     "background":"是否接受跨专业背景","requirements":"申请材料",
     "applicationOpen":"申请开放时间","deadline":"申请截止时间",
     "deadlineNote":"截止备注（如分轮/rolling）","updated":"2026-09"}
  ]
};
```

## 术语小词典（给编程小白）

- **静态网站**：只有网页文件，浏览器打开就渲染，没有后台程序。
- **部署/上线**：把整个 `uni-guide` 文件夹传到免费托管（如 GitHub Pages），
  得到一个公网网址，任何人联网都能打开。
- **JSON**：纯文本的数据格式，网站数据都存在里面。
- **slug**：网址里代表一个条目的英文短串，如 `digital-marketing-strategy-msc`。

## 首页徽章说明

榜单里每所学校旁有一个小标签：
- **有课程数据**（黑色边）＝ 该校正由官网采集完毕，可点击查看课程
- **整理中**（灰色）＝ 正在采集，点击后仍可先看学校官网

标签由 `data/manifest.js` 自动生成（`python3 build_manifest.py`），
以后每完成一所学校，跑一次该脚本即可在首页点亮。
